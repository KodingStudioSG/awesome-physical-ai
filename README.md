## Learning Physical AI

New to the field, switching into robotics, or trying to understand what skills Physical AI roles actually require? See the [Learning Physical AI guide](learning/README.md).

It includes practical paths for:

- **Robotics software engineering** - Python/C++, Linux, ROS 2, kinematics, planning, and manipulation.
- **Perception and autonomy** - Computer vision, deep learning, state estimation, mapping, and autonomous systems.
- **Controls and motion** - Dynamics, feedback control, trajectory optimization, and model-predictive control.
- **Robot learning and embodied AI** - PyTorch, imitation learning, reinforcement learning, LeRobot, and simulation.
- **Simulation and validation** - Physics simulation, synthetic environments, sensors, and reproducible testing.

The guide emphasizes durable first-party learning resources and portfolio projects that can translate directly into job-ready evidence. When you are ready to apply what you learned, browse current roles at [PhysicalAI.jobs](https://www.physicalai.jobs/jobs).

## Open Source

- [ROS 2](https://docs.ros.org/en/rolling/) - Open-source middleware and tools for building distributed robotics systems.
- [Gazebo](https://gazebosim.org/) - Open-source robotics simulator for sensors, environments, and robot dynamics.
- [MuJoCo](https://mujoco.org/) - Open-source physics engine widely used for robotics, control, and reinforcement learning.
- [Drake](https://drake.mit.edu/) - Model-based design and optimization toolbox for robotics and control.
- [Isaac Lab](https://isaac-sim.github.io/IsaacLab/) - Open-source framework for robot learning built on NVIDIA Isaac Sim.
- [LeRobot](https://github.com/huggingface/lerobot) - Hugging Face project for datasets, models, and tooling for real-world robotics.
- [ManiSkill](https://maniskill.readthedocs.io/) - Simulation and benchmark framework for robot manipulation and embodied AI.
- [robosuite](https://robosuite.ai/) - Robot learning simulation framework built around MuJoCo.
- [Webots](https://cyberbotics.com/) - Open-source robot simulator supporting mobile robots, manipulators, sensors, and controllers.
